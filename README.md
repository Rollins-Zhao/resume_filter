# 简历筛选工具 · 猎聘 + BOSS直聘

帮你把两个招聘平台的候选人**自动搜出来、按你的标准打分、生成 Excel 推荐报告**。
**它默认绝不自动打招呼、绝不群发消息、绝不交换联系方式**——联系谁、说什么，永远由你决定；工具只负责把对的人找出来、排好序、写清楚。（唯一可选项：BOSS 侧「自动打招呼」，须你首次使用时明确点头开启，见下文。）

适合 HR / 招聘负责人。可以纯双击使用（不需要懂任何技术）；配合能读写文件的 AI 助手（WorkBuddy / 豆包 / Claude Code 类）体验更佳。

## 一句话装机 / 升级（推荐，配合 WorkBuddy / 豆包等 AI 助手）

在 AI 对话里直接说这句（**复制发给同事即可**——新同事、旧版本升级、换电脑都适用）：

> 请拉取并安装 GitHub 开源项目 Rollins-Zhao/resume_filter（猎聘+BOSS简历筛选工具），装好后告诉我怎么开始。

**给 AI 的执行指引**（用户这样说时按本节操作，全程不需要 git）：

1. 先问用户：**以前装过吗？装过的文件夹在哪**（有 `run.bat` 的那个文件夹）。
   - **装过（升级）**：把下面下载的 zip **覆盖解压到原文件夹**——`profiles/_user.json`、`data/`、`reports/`、`logs/` 都不在 zip 里，用户数据不会被动到。
   - **没装过（新装）**：新建一个专用文件夹（如 `D:\resume_filter`），解压到那里；以后所有数据都在这个文件夹。
2. 下载最新发布包（约 0.4MB）：
   `curl -L --retry 5 --retry-all-errors -o resume-screener-latest.zip https://github.com/Rollins-Zhao/resume_filter/releases/latest/download/resume-screener-latest.zip`
3. 解压 zip 到目标文件夹（zip 内没有顶层文件夹，直接平铺）：优先 PowerShell
   `Expand-Archive -LiteralPath 'resume-screener-latest.zip' -DestinationPath '<目标文件夹>' -Force`，
   或 `C:\Windows\System32\tar.exe -xf resume-screener-latest.zip -C "<目标文件夹>"`。注意：git-bash 里的 GNU tar 不认 zip，别用。
4. 在目标文件夹跑 `node doctor.js --json` 自动装依赖（exceljs / liepin-cli / uv / boss-agent-cli / 浏览器内核，国内镜像优先，首次约 3-10 分钟）；`criticalReady=false` 就把 `userActions` 逐条转达给用户，处理完再继续。随后跑 `node ai-guide-sync.js --all`，把最新 AI 契约写进各平台记忆文件（用户新对话的开工指令才会上线——覆盖升级旧文件夹时**必须**跑这一步）。
5. 引导用户：双击登录器扫码（猎聘 `liepin-login.bat`；BOSS `boss-edge-login.bat` 或 `boss-zhipin-login.bat`，**窗口保持开着**）。
6. **装机收尾不要引导用户双击 `run.bat`**——AI 在场时这一步多余，直接接着干：按 AI-GUIDE 第 0 步在对话里问背景四项（+1 个可选补充问）写入 `profiles/_user.json`，然后告诉用户**直接说招聘需求就行**（如「我在猎聘上招销售经理，帮我筛简历」），后续按对应 SKILL.md 由 AI 执行到底。`run.bat` 留给没有 AI 助手的场景。
7. 告诉用户：以后**不用再装**——`run.bat` 每次启动自动升级到最新版（v2.13.0 起内置），日常什么都不用做。

没有 AI 助手？双击 `install.bat`（新机器引导安装器），或到 [Release 页](https://github.com/Rollins-Zhao/resume_filter/releases/latest) 手动下载 zip 解压后走下面「三步开始」。

## 三步开始

1. **双击 `setup.bat`** —— 一次性装依赖（首次约 3-10 分钟；只用猎聘的话，BOSS 部分可以跳过）
2. **双击登录器扫码**（窗口**保持开着**，关窗=掉登录）：
   - 猎聘：`liepin-login.bat`
   - BOSS直聘：`boss-edge-login.bat`（Edge）或 `boss-zhipin-login.bat`（Chrome）
3. **双击 `run.bat`** —— 第一次会先用 4 个小问题认识你（公司名/行业/业务方向/常用城市，都可回车跳过），最后还有 1 个可选补充问（回车跳过，补充内容会并入"业务方向"），然后菜单选平台和岗位，等它跑完，去 `reports/` 拿 Excel

**BOSS 直聘筛选的三个小要求（v2.10.0 更新）**：① 登录浏览器里要有**沟通页**（`zhipin.com/web/chat`）标签页——BOSS 2026-10 下线了旧简历接口，看简历正文需要它；**工具会自动检查，没有会自动帮你开一个，保持别关即可**；② **筛完自动识别正文**：平台把简历正文加密画成图（DOM 里没有文字），工具筛选时会逐份**截图**并当场用**本机文字识别（RapidOCR，离线）**转成文字再打分——零费用、不外发（识别偶发不过的个别份才需要 AI 帮忙读图转写，工具会明确提示）；③ **筛选时浏览器窗口别最小化**（工具检测到会自动还原），最小化/被完全遮挡会让滚动截图超时。报告新增「牛人分析」列：平台对候选人的活跃度分析（如"牛人38分钟前浏览过职位"），从官方接口明文免费获取。

**BOSS 自动打招呼（v2.7.0 起，可选，默认关）**：第一次跑 BOSS 时工具会问你「筛选完要不要自动给 S/A 级候选人发首条招呼」——不开启就永远保持纯只读筛选，之后也不再追问。开启后再二选一话术来源：**按岗位建议话术**（报告「建议打招呼话术」那列，各岗位可不同）或**固定话术**（你自己写一段，会给一份带占位符的草稿，可改可从零写）。安全边界：只发本轮**真实浏览过**、最终评分 **S/A** 的人；同一个候选人**全局只发一次**（换岗位也不会再打扰第二次）；每天本地最多 **20 条**；发送间隔 60–180 秒随机；话术发送前自动检查（超 120 字、带链接/联系方式的直接跳过并在报告里写明原因）；报告新增「打招呼」列记录每个人发没发、为什么没发。随时 `run.bat --setup-greet` 关闭或换话术。（原「S/A 级自动收藏」已于 v2.7.0 移除：平台对未沟通候选人关闭了收藏接口，实测无效。）

**⚠️ 2026-10-29 状态：暂停中**。真机试水发现平台对搜索来源的自动打招呼会「假成功」——接口回执成功、沟通列表却查不到任何会话，消息根本没投出去。v2.7.1 已止血：搜索来源的候选人一律不自动发（报告标「未发(需手动)」，请用「BOSS简历」列链接手动联系）；今后任何发送都要回查沟通列表、核实到会话才算成功。恢复自动待病因定案（详见仓库 BUG-2026-10-29 文档）。

## 新岗位怎么做？

**最省事：只报岗位名。** 双击 `run.bat`，菜单选 `0. 从已发布岗位新建`——工具会读你在平台上**已发布的在招岗位**，挑一个，自动生成岗位配置（含城市），回车确认就开跑。也可以直接对 AI 说：「我在猎聘上招销售经理，帮我筛」——AI 会先查你的在招岗位，匹配上就起草配置给你确认。

报的名字没匹配上？工具会把在招岗位列出来让你挑，确实没有再让你描述要求。命令行用法：`run.bat liepin --from-published`（只看列表）、`run.bat liepin --from-published 销售经理`（按名生成配置）。

其他方式：把岗位要求**用自然语言告诉 AI**（它会生成配置文件）；或复制 `profiles/_template.json` 手填（照着 `example-销售经理.json` 改）。

## 公司名/行业背景变了，怎么改？

**说一次就记住了。** 你交代过的公司背景记在 `profiles/_user.json`，之后生成岗位配置、报告里的打招呼话术（`我们是{company}`）自动带上，不用每次重复介绍。修改三选一：`run.bat --setup-user` 重新引导（回车=保留现值）；记事本直接编辑；删掉文件下次自动重新引导。在 AI 对话里提到新背景时，AI 会先跟你确认再更新。**AI 如果没问你就想开跑**：2.3.2 起工具会强制拦截（筛选启动时发现档案不存在直接拒绝执行，AI 会回过头来问你公司/行业等四项）——机器保证，不靠 AI 自觉。引导末尾可选补充问的回答以「；补充：…」并入「业务方向」字段，不另立字段。

## 换其他 AI 平台（豆包 / Claude Code / Cursor 等）怎么用？

默认配合 **workbuddy**：安装时 setup.bat 已自动把使用契约写进 workbuddy 的记忆文件。换平台只需一条命令把契约同步到新平台的记忆文件：`node ai-guide-sync.js doubao`（已预设 doubao/claude/codex/cursor）；没预设的平台先注册再同步：`node ai-guide-sync.js --add 平台名=该平台AI自动读取的文件路径`。也可以直接对 AI 说"我要换 X 平台用"，它会问你该平台读哪个文件然后自动完成。契约权威源是项目里的 `AI-GUIDE.md`——改它之后重新同步即可。

## 报告里的 BOSS 链接怎么用？

「BOSS简历」列点开会到 BOSS **沟通页的搜索**（你自己平时用的浏览器、已登录 BOSS 就能点）。把同一行的**「搜索串」**（比如「冯 腾讯科技 高级产品经理」）粘进搜索框回车，目标人**通常排在最前面**；按表格里的**称呼+年限+年龄**三列和卡片对照确认——点卡片就能看在线简历，点「联系」就能沟通。

两个提醒：① **平台收费规则**——对搜索找到的人点「联系」会弹「搜索畅聊卡」购买（按人头收费）；推荐来源的候选人（工具已自动打过招呼的）在沟通列表里直接回话就行，不涉及收费。② BOSS 把姓名脱敏成「冯**」（真名要等建立沟通后才可见），所以表格用「称呼」列对照。「抓取时间」列告诉你数据是什么时候抓的。**猎聘报告的链接是稳定的简历直达链接，随时可点**——两侧链接形态不同是有意设计。

## 每天能看多少简历？

**每个平台每天最多成功浏览 1000 份**（猎聘、BOSS 各 1000，用完自动跳过筛选只出报告，次日自动恢复；只算成功打开的简历，缓存和被拒的不算）。多个岗位自动**均分剩余额度**——新增岗位配置会自动参与重新分配；想给某岗位单独限量，在配置里写 `"dailyResumeQuota": 300`。用量看 `run.bat` 结尾汇总，或直接开 `data/_quota/liepin.json` / `boss.json`。两个提醒：单岗位一天还受请求数上限保护（猎聘 200 / BOSS 120），多岗位才可能用满 1000；同一平台**别同时开两个 `run.bat` 窗口**。

## 工作时间窗口是什么？

**工具默认只在每天 8:00–20:00 干活**（按你电脑的时钟），避免深更半夜还在操作账号、被平台识别为自动化——到点它会正常收尾出报告，**不是出错**。想改窗口：对 AI 说一声（如"把工作时间改成 9 点到 18 点"）或记事本改 `profiles/_user.json` 的 `settings.workingWindow`。偶尔急用：`run.bat --anytime` 临时越过（风险自担）。

## 历史文件会一直堆积吗？（v2.11.0 起自动清理）

**不会**：每次启动工具会自动清理**超过 1 天**的中间文件——运行日志、简历缓存、评分缓存、BOSS 截图（都是含个人信息的中间产物，过期即清反而更安全）。**报告文件（Excel）、"已经推荐过谁"的去重记录、配额账本永不删除**——隔天回看报告、去重和限额照常有效。保留期想改：对 AI 说一声（如"历史文件保留改成 7 天"或"把自动清理关掉"），或记事本改 `profiles/_user.json` 的 `settings.retentionDays`（数字=天数，`0`=关闭清理）。注意：保留期内的当日数据不受任何影响；隔天的缓存会被清，想隔天补出报告/重新评估需要重新筛一轮。

## 每次运行会搜哪些岗位？

**岗位是"点播"不是"订阅"**：一次运行只处理你选定的那一个岗位，之前跑过的岗位不会自动重跑——想跑就再运行一次 `run.bat` 选它（对 AI 说"把 XX 岗位再跑一轮"也行）。**重跑老岗位是增量模式**：只找上次没看过的新候选人（看过的不再浪费请求），已推荐过的人也不再重复进报告；新岗位第一次跑是全量。各岗位的数据、去重记录、报告完全独立，只有每天 1000 份额度是共享的。

## 报告里为什么没有某个人？

三种可能：① 他之前已经进过一次报告（**推荐去重**：同一岗位同一人只推荐一次，**跨一轮筛选才跳过**——同一轮里重出报告不算重复、照常出现，v2.9.0 起；重置=删 `data/<岗位>/<平台>/recommended-index.json`；想让他再出现一次用 `run.bat --dup`）；② 画像把入表门槛收紧了（**默认全量收录所有等级**，v2.9.1 起；若画像里 `minReportGrade` 钉了 "A"/"S"，低于该级的不进表）；③ 被硬筛掉（配置里 `reportFilters` 的年龄/学历/必命中维度）。报告第二个工作表"已推荐过(本次跳过)"会告诉你谁因去重被跳过。

**BOSS 报告的「年龄/学历/年限」三列为什么是空的？** 这是平台侧原因：BOSS 2026-10 下线旧简历接口后，只返回简历骨架，不再提供这三个字段（真机验证 18/18 份全空）。不是抓取故障——工具**有意不做**从正文里猜年龄学历的"兜底解析"（猜错了比空着更误导）。这三项信息在在线简历正文里都有，点报告里的 BOSS 链接直接看。

## 怎么换城市 / 跑多个城市？

岗位配置里 `"city": "北京"` 是单城；加 `"cities": ["北京", "上海"]` 就是逐城跑（城市间自动休整 5 分钟）。临时单城：`run.bat liepin 销售经理 --city=上海`。

## 怎么调整打分标准？

改岗位配置里 `scoring` 的关键词和权重（让 AI 改最方便："把业绩维度权重提高、加上 XX 关键词"），然后 `run.bat liepin 销售经理 --report-only` ——基于已下载的简历**零网络重算**并出新报告，不消耗额度。方法论见 `liepin-resume-screener/references/scoring-model.md`。

## 快速评估和精细评估是什么？怎么切换？（v2.6.0 起；v2.9.0 起精细有强制门槛）

两种简历评估方式，工具两种都支持，随时可换：

- **快速评估（默认）**：规则引擎，免费、秒级，按关键词匹配打分——效率高，但颗粒度粗（同义表述可能漏、自我评价可能误判）。
- **精细评估**：AI 逐份读简历的**工作内容**、按你的岗位要求打分，附「匹配依据」（引用简历原文）——更准，但每份简历消耗模型积分/token（约 3k token/份，20 份一轮约 10 万级）。

切换直接对 AI 说：「这批候选人精细评估一下」（只这一批）或「以后都用精细评估」（改默认偏好，run.bat 首次引导也会问一次）。

**v2.9.0 起的两点变化**（此前"选了精细"实际不会自动执行、拿到的还是关键词分——已修复）：

1. **选了精细=硬门槛**：默认偏好设为精细后，筛选完成 → AI 精细评估 → 才出报告；评估没做完时**报告不会生成**（工具明确提示"精细评估未完成"，而不是悄悄给你一份快速分的报告）。本次想跳过评估直接出报告：对 AI 说"这次用快速档"或运行时设 `SCREENER_FORCE_FAST=1`。双击 run.bat 跑的话，筛选完成后会问你「现在停下交给 AI 评估 / 本次降级快速」。
2. **报告首行标明口径**：每份报告第一行固定写着「评估方式：快速 / 精细（LLM 语义评估 N/M 份）」——一眼就能确认拿到的是哪种分数。

精细评估随时可中断——评过的用 AI 分数，没评的用快速分数；中断后想出报告需临时降级快速档（见上）。跑很多份（如几百份）时工具会分批给、评完的批次即时落盘，换新对话说「继续评估」即可接着来，不白花积分。

## 安装失败 / 登录失效怎么办？

- **工具自动保持最新**：每次运行都会自动检查猎聘/BOSS 命令工具**和工具本体**是不是最新版，不是就自动升级（本体更新走 GitHub，v2.13.0 起）——**不需要手动更新**；升级失败（如断网）只提示一句，不影响本次使用。
- **安装失败**多为网络问题：换网络重跑 `setup.bat`；BOSS 浏览器内核约 200MB 走国内镜像，首次运行 `run.bat` 时也会自动补装。
- **提示登录失效**：重新双击对应登录器扫一次码就好；**千万不要反复重登**——反复重登正是账号被判异常的主因。
- **触发风控/验证**：立即停下休息一段时间再用，别连续重跑。工具自己也带三层防护：浏览节奏放慢（看一份歇 25–55 秒、每连看 5 份多歇 1–3 分钟）、运行中一旦出现**网页频繁刷新或被弹回登录页**会**自动立即停止**、触发风控后留一把"风控锁"拦住下一次运行——人工确认账号恢复正常并冷却后，删除提示里说的那个锁文件即可恢复。

## 转发 / 装给同事（v2.13.0 起更简单）

- **新同事装机（推荐）**：把 `install.bat` 这一个小文件发给 TA——放进一个专用空文件夹（如 `D:\resume_filter`）双击，自动下载安装最新版，然后照提示 setup.bat → 登录器 → run.bat 三步走。装好后**永远自动更新**，不用再发任何包。
- **存量同事（v2.13.0 之前装的）**：**最后一次**手动升级——把 `pack-release.bat` 打出的 zip（在 `release/`，只含工具和模板）发给 TA，解压覆盖旧文件夹即可（数据目录不在包里，安全）；此后全自动。
- 继续用 zip 手动分发也完全可以：只用 `pack-release.bat` 重新打包再发。**绝对不要右键压缩整个文件夹**——那会把你的真实岗位配置、候选人简历缓存和报告一起发出去。这个包可以一直往下传（A→B→C），每层都用同一个打包脚本。
- 维护者发新版到 GitHub：**先 `git push`、再 `pack-release.bat --publish`**（一条命令完成打包 → 建 Release → 上传 版本zip / latest.zip / install.bat 三个资产；顺序反了 tag 会打在旧代码上，需 `.env` 配 `github_token`）。发出去之后，装过 v2.13.0 的同事下次启动自动升级。

## 数据安全（重要）

`data/`、`reports/`、`logs/` 里是**真实候选人个人信息**，只保存在你本机：不上传网盘、不进 git 仓库（`.gitignore` 已配好）、不随文件夹外发。

## 让 AI 认识这个工具（可选）

两个 skill 文件夹（`liepin-resume-screener/`、`boss-resume-screener/`）就是给 AI 读的说明书 + 全部脚本：复制到 `C:\Users\<你的用户名>\.workbuddy\skills\`（豆包/Claude Code 等同类目录亦可），对话里说"用猎聘筛选 SKILL"即可命中；或把文件夹路径告诉 AI 按里面的 SKILL.md 执行。不装也完全能用——`run.bat` 就是给纯双击用户的。

## 目录结构

```
├── run.bat / run.js            # 统一入口：选平台+岗位（菜单 0=从已发布岗位新建）→ 自检 → 逐城筛选 → 出报告
├── self-update.js              # 工具本体自更新（run.bat 启动时自动查 GitHub Release 升级，v2.13.0）
├── install.bat                 # 新同事引导安装器（放进空文件夹双击即装最新版；也可不随包分发）
├── setup.bat                   # 一次性安装（猎聘 + BOSS 双平台）
├── liepin-login.bat            # 猎聘登录启动器    boss-edge-login.bat / boss-zhipin-login.bat # BOSS 登录
├── liepin-resume-screener/     # 猎聘 skill（SKILL.md + references + scripts）
├── boss-resume-screener/       # BOSS skill（同构）
├── profiles/                   # 岗位配置（一岗一文件）+ _user.json 用户背景档案
├── data/                       # 运行数据（按 岗位/平台 隔离，自动生成）
├── reports/                    # Excel 推荐报告输出
└── pack-release.bat / .js      # 打干净包转发给同事（--publish 一条命令发 GitHub Release）
```
